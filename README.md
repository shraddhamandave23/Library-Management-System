Library Management System

Project Overview

The Library Management System is a Java-based application developed using Java, MySQL, and JDBC. It helps manage library books and maintain book records efficiently.

Technologies Used

- Java
- MySQL
- JDBC
- GitHub

Features

1. Add New Books
2. View All Books
3. Search Books
4. Update Book Details
5. Delete Books
6. Issue Books
7. Return Books

Database

MySQL is used to store book information and issue records.

Project Objectives

- Understand Java Database Connectivity (JDBC).
- Connect Java applications with MySQL.
- Perform CRUD operations.
- Manage library records efficiently.
